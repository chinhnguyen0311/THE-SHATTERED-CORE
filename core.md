1. CORE SYSTEM

Đây là hệ thống quan trọng nhất.

Sau mỗi ải:

      Reward
        ↓
    3 Core xuất hiện
        ↓
      Chọn 1
        ↓
    Build thay đổi

    Core có 3 cấp:

    Core nhỏ: Tăng chỉ số.
    Core trung: Thêm gameplay 
        ví dụ: Attack có 20% Burn
    Core lớn: Thay đổi cách chơi.
        ví dụ: Mỗi lần Dash → tạo Fire Trail

    CORE CÓ THỂ XẾP CHỒNG
    
        Ví dụ:

        Fire Core I
        Fire Core II
        Fire Core III

        → Burn mạnh hơn.

2. CORE ARCHETYPE

    FORCE CORE
    
        Tập trung:
            ATK
            DEF
            melee
            crit
            stagger
        Build: Warrior

    ARCANA CORE

        Tập trung:
            Mana
            Magic Damage
            Cooldown
            Skill

        Build: Mage

    ELEMENT CORE

        Tập trung:
            elemental damage
            status effect
            elemental combo

        Build: Elementalist

    LIFE CORE

        Tập trung:
            HP
            regeneration
            summon
            sustain

        Build:Druid

    SPIRIT CORE

        Tập trung:
            summon
            soul damage
            mana drain
            curse

        Build: Soul Master

    VOID CORE

        Tập trung:
            damage cực lớn
            sacrifice HP
            xuyên DEF
            manipulation

        Build: Void Walker

3. CORE SYNERGY

    Core không nhất thiết độc lập.
        Ví dụ:
        Force + Fire
        = Burning Weapon

        Arcana + Lightning
        = Chain Spell

        Life + Poison
        = Toxic Growth

        Spirit + Void
        = Soul Collapse

        Ice + Physical
        = Shatter Build
